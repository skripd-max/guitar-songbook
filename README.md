# Гитарный песенник

Автономное PWA для личной библиотеки песен с аккордами. Работает без сервера после первой загрузки; песни хранятся в `localStorage` браузера.

## Локальный запуск

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Проверка логики: `node tests.mjs`.

Для установки на iPad сайт должен быть доступен по HTTPS (либо опубликован на статическом хостинге). Откройте адрес в Safari, нажмите «Поделиться» → «На экран Домой».
